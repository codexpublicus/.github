# .github

The default community health files for the Codex Publicus organization's repositories
(the security policy, the contributing guide, the issue forms and the pull request
template) and the organization's profile page (`profile/README.md`). GitHub shows each
health file on any repository here that doesn't have its own file of that type.

These files are published from codexpublicus/infra, and an edit made here directly is
overwritten on the next update.
