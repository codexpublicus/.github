# Codex Publicus

Codex Publicus keeps the law readable by anyone, without an account, a subscription or a
server that can go away. Every project publishes static files that anyone can mirror, and
runs from a mirror with no network.

## Projects

- [stare.pub](https://stare.pub/) resolves U.S. case law citations to the opinion text and
  the original scanned reporter page, built on the Harvard Caselaw Access Project.
- [The Neil Gorsuch Library](https://gorsuch.codexpublicus.org/) has every opinion and
  writing of Justice Neil Gorsuch, with the source documents they were read from, as a
  site and as a dataset.

Court opinions are public domain. Each project states its own code and data licenses.

More at [codexpublicus.org](https://codexpublicus.org/).
